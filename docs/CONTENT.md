# WoW Forever Talent Design Atlas — Research Inventory

**Author:** Babuni.dev  
**Snapshot:** October 2026 beta, as described in the committed atlas.

## Primary publications

- `README.md` is the complete expanded Markdown review: nine original classes, 27 trees, 466 talent classifications, class and tree analysis, examples and limitations.
- `WoW_Forever_Talent_Design_Atlas.pdf` is the committed companion PDF edition. It has **not** been freshly compared page-by-page against the current README in this audit.
- `CONCEPT.md`, `ROADMAP.md`, `CHANGELOG.md`, `AGENTS.md` and `docs/` contain project-history, provenance and editorial guidance rather than an independent talent database.

## Nine class chapters

Warrior (Arms, Fury, Protection); Rogue (Assassination, Combat, Subtlety); Warlock (Affliction, Demonology, Destruction); Mage (Arcane, Fire, Frost); Hunter (Beast Mastery, Marksmanship, Survival); Shaman (Elemental, Enhancement, Restoration); Priest (Discipline, Holy, Shadow Magic); Druid (Balance, Feral Combat, Restoration); Paladin (Holy, Protection, Retribution).

## Analytical layers

Each classification pairs a talent with an authorial judgment and short reason; the class sections add interpretive commentary, examples, and conclusions. Aggregated rankings summarize the same reviewed snapshot. Later illustrative redesign tables explore what an ability interaction *could* look like, not a promise or balance-tested proposal.
