# wowforeverstuff — architecture and content

**Author:** Babuni.dev

README.md is a long-form research report covering all nine original classes, 27 trees and 466 rated talents, with the accompanying PDF edition. The repository is a design-study archive, not a runnable addon.

This is a static repository description. No live-system execution or fresh beta research was conducted.

## Publication architecture and verification

The content is a long Markdown report in the root README, not runtime software. It progresses from methodology to nine-class summary and 27-tree rankings, then class-by-class tables, commentary, optional redesign exercises, and limitations. A companion PDF is committed as a published representation. The new design/content guides provide portfolio navigation rather than duplicating the individual talent dataset.

The source methodology describes subjective categories applied once to each of 466 talents in an October 2026 beta snapshot. Neither a data extraction script nor an independent current-tooltip verification was identified during this documentation review. Any future audit should compare individual rows to the relevant dated game build and verify PDF parity before revising headline totals.
